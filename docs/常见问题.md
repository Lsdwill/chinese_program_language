# 常见问题

## 需要安装 Python 吗？

不需要。发布包是独立的 Go 程序；从源码构建只需要 Go 1.22 或更高版本。

## 源文件可以使用 `.华` 吗？

可以。`.hua` 和 `.华` 都会经过同一套 Lexer、Parser、Resolver、Compiler 和 VM。

## 为什么模块导入失败？

模块名必须和相对项目根的路径一致。例如 `服务/用户.hua` 应声明 `模块 服务.用户`。导入路径不能使用绝对路径、`..` 或目录分隔符。

## 为什么字典顺序没有改变？

华言字典保留插入顺序；更新已有键不会把它移动到末尾。JSON 序列化也遵循这个顺序。

## 如何运行图书馆示例？

在仓库根目录执行 `huayan examples/图书馆/主.hua`。程序使用示例目录下的 `数据/`，从其他工作目录启动也会定位到执行模块目录。

## 如何报告问题？

请同时提供最小 `.hua` 源码、执行的命令、华言版本、完整中文诊断和操作系统；涉及数据文件时先保留原文件及 `.bak` 备份。
