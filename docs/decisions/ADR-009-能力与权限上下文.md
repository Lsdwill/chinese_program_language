# ADR-009：能力与权限上下文

状态：已接受

## 背景

SQLite、网络和项目清单会让原生模块接触宿主资源。仅在注册表中记录能力而不在运行时检查，无法阻止受限项目执行文件、环境或网络操作。

## 决策

新增独立的 `internal/capability` 包，提供值语义的能力集合：

- `New(...)` 创建有限能力集合；
- `AllowAll()` 表示直接执行脚本的兼容模式；
- `Allows` 和 `Require` 提供确定性检查；
- 缺失能力统一返回权限错误。

VM 持有执行能力集合。直接创建 VM 时默认允许全部能力，保持 v0.3 单文件脚本行为；项目运行器或嵌入者可以替换为有限集合。

文件标准模块按操作检查文件读取或文件写入，`标准.程序.环境` 检查环境读取。参数校验在权限检查之后执行，确保未授权操作不会泄露路径或宿主环境细节。

## 后续

SQLite 模块使用数据库能力，HTTP 客户端和服务器分别使用网络客户端、网络监听能力。项目清单解析完成后，由 Engine 在创建 VM 前注入有限能力集合。
