# 华言 v0.4.0

华言 v0.4.0 是第二阶段运行时基础版本，增加资源管理、能力权限、不可变字节串、编码能力和中文数据库查询。

## 主要变化

- 新增原生模块注册表和能力声明；
- 新增 VM 资源管理器、显式关闭和逆序兜底关闭；
- `尝试` 支持 `最后` 清理分支；
- 新增不可变字节串，支持 UTF-8、Base64 和十六进制编码；
- 文件模块支持二进制读写；
- 新增 `标准.数据库` 中文数据库模块；
- 支持建表、插入、选择、更新、删除和事务；
- 支持中文查询语法糖：`选择`、`其中`、`排序`、`限制`；
- 数据库动态值使用参数绑定，表名和字段名执行安全校验；
- 保持 v0.3 旧代码兼容，包括将“选择”作为普通变量名的代码；
- README、标准库 API 和第二阶段增量规范同步更新。

## 查询示例

~~~text
导入 标准.数据库 为 数据库
让 库 = 数据库.打开(":memory:")
数据库.建表(库, "图书", 记录 {编号: "文字", 书名: "文字"})
数据库.插入(库, "图书", 记录 {编号: "B001", 书名: "活着"})
让 结果 = 选择 图书 从 库
    其中 编号 等于 "B001"
    排序 书名 升序
    限制 20
结束
打印(结果[0].书名)
数据库.关闭(库)
~~~
