# 华言语法参考

本文档描述华言 v0.4 的常用语法。华言源文件使用 UTF-8 编码，扩展名为 `.hua`，也支持 `.华`。

## 1. 源文件和注释

程序由顶层声明、函数定义、导入语句和表达式组成。语句通常以换行分隔，也可以使用分号。

```text
# 这是注释
让 名字 = "华言"
打印(名字)
```

标识符支持中文、英文、数字和下划线，但不能以数字开头。关键字包括 `让`、`常量`、`函数`、`如果`、`否则`、`当`、`遍历`、`返回`、`结束`、`尝试`、`捕获`、`最后`、`抛出`、`导入` 和 `为`。

## 2. 值和字面量

```text
让 整数 = 42
让 小数 = 3.14
让 真值 = 真
让 假值 = 假
让 空值 = 空
让 文字 = "你好，华言"
让 列表 = ["甲", "乙", "丙"]
让 字典 = {名称: "华言", 版本: 4}
让 图书 = 记录 {编号: "B001", 书名: "活着"}
```

列表通过下标访问，记录和字典通过字段访问：

```text
打印(列表[0])
打印(图书.书名)
图书.书名 = "许三观卖血记"
```

## 3. 变量、赋值和运算

`让` 创建可重新赋值的变量，`常量` 创建不可重新绑定的常量。

```text
让 次数 = 1
次数 = 次数 + 1
常量 上限 = 10
```

支持算术、比较和逻辑运算：

```text
让 总价 = 单价 * 数量
如果 总价 >= 100 且 会员 == 真
    打印("享受优惠")
结束
```

常用运算符包括 `+`、`-`、`*`、`/`、`%`、`==`、`!=`、`<`、`<=`、`>`、`>=`、`且`、`或` 和 `不`。

## 4. 条件和循环

```text
如果 分数 >= 60
    打印("通过")
否则
    打印("继续学习")
结束
```

```text
让 数字 = 1
当 数字 <= 3
    打印(数字)
    数字 = 数字 + 1
结束
```

```text
遍历 图书 于 图书列表
    打印(图书.书名)
结束
```

循环中可以使用 `继续` 和 `跳出`。带 `最后` 的资源管理语句中，建议使用布尔变量控制循环结束，以确保清理逻辑始终执行。

## 5. 函数

```text
函数 加法(左, 右)
    返回 左 + 右
结束

打印(加法(2, 3))
```

函数支持递归、嵌套和闭包：

```text
函数 创建计数器()
    让 次数 = 0
    函数 计数()
        次数 = 次数 + 1
        返回 次数
    结束
    返回 计数
结束
```

## 6. 模块

使用 `导入` 引入标准库或项目模块，并使用 `为` 设置本地名称：

```text
导入 标准.文件 为 文件
导入 标准.数据库 为 数据库
```

模块文件中的公开声明可以被其他模块使用。命令行直接执行的源文件通常在结尾调用主函数：

```text
函数 主()
    打印("程序启动")
结束

主()
```

运行方式：

```bash
huayan 程序.hua
huayan check 程序.hua
huayan dis 程序.hua
```

## 7. 异常和资源清理

```text
尝试
    抛出 错误("发生错误")
捕获 原因
    打印(原因.消息)
最后
    打印("清理资源")
结束
```

`最后` 无论正常执行还是发生异常都会执行，适合关闭文件、数据库和事务资源。

## 8. 中文数据库查询语法

华言数据库模块底层使用 SQLite，但程序员不需要书写 SQL：

```text
导入 标准.数据库 为 数据库

让 库 = 数据库.打开("图书馆.db")
数据库.建表(库, "图书", 记录 {编号: "文字", 书名: "文字", 年份: "整数"})
数据库.插入(库, "图书", 记录 {编号: "B001", 书名: "活着", 年份: 1993})

让 结果 = 选择 图书 从 库
    其中 编号 等于 "B001"
    排序 书名 升序
    限制 20
结束

打印(结果[0].书名)
数据库.关闭(库)
```

查询语法由 `选择`、`从`、`其中`、`等于`、`排序`、`升序`、`降序` 和 `限制` 组成。数据库 API 还提供：

```text
数据库.选择一行(库, "图书", 记录 {编号: "B001"})
数据库.更新(库, "图书", 记录 {书名: "新书名"}, 记录 {编号: "B001"})
数据库.删除(库, "图书", 记录 {编号: "B001"})
让 事务 = 数据库.开始事务(库)
数据库.提交(事务)
数据库.回滚(事务)
```

字段类型使用中文名称：`文字`、`整数`、`小数`、`布尔` 和 `字节串`。
