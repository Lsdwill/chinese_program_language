# Python 与 Lua 迁移差异

华言使用中文关键字、动态强类型值模型和显式块结束符。迁移时应先把代码拆成小函数，再逐步替换容器和模块访问。

| 主题 | 华言 | Python | Lua |
| --- | --- | --- | --- |
| 变量 | `让 名字 = 值` | `名字 = 值` | `名字 = 值` |
| 常量 | `常量 名字 = 值` | 约定或类型检查 | 约定或闭包 |
| 函数 | `函数 加一(x) ... 结束` | `def 加一(x):` | `function 加一(x) ... end` |
| 空值 | `空` | `None` | `nil` |
| 布尔值 | `真`、`假` | `True`、`False` | `true`、`false` |
| 列表 | `[1, 2]`，索引从 0 开始 | `list`，索引从 0 开始 | table，通常从 1 开始 |
| 字典 | `{"名": "华言"}` | `dict` | table |
| 模块 | `导入 标准.JSON 为 JSON` | `import` | `require` |
| 块 | `结束` | 缩进 | `end` |

华言的 `且`、`或` 要求操作数为布尔值，不采用 Python/Lua 中以任意对象表示真值的规则。字典键只允许文字、整数和布尔值；记录字段使用 `记录 {名: 值}`。

迁移 Lua 时尤其注意索引基准、`空` 的处理和表的双重用途；迁移 Python 时注意没有隐式异常转换，文件和 JSON 错误必须显式处理或交给 `尝试`/`捕获`。
