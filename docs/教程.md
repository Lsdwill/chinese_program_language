# 华言 v0.3.0 快速教程

## 安装与运行

从发布包解压 `huayan`（Windows 使用 `huayan.exe`），即可运行：

```text
huayan examples/你好世界.hua
huayan check examples/核心演示.hua
huayan fmt --check examples/核心演示.hua
huayan test tests/conformance
```

华言源文件是 UTF-8，语句通常按换行分隔，也可以使用分号。变量使用 `让`，不可重新赋值的绑定使用 `常量`。

```text
让 名字 = "华言"
函数 问候(对象)
    返回 "你好，" + 对象
结束
打印(问候(名字))
```

函数可以嵌套并捕获外层变量。列表、字典和记录分别使用 `[]`、`{}` 和 `记录 {}`；字段和索引都可以读取或写入。

## 模块

项目模块按点号路径导入，只有 `公开` 声明能够从其他模块读取：

```text
导入 标准.JSON 为 JSON
从 图书馆.模型.图书 导入 创建
```

标准文件路径相对当前模块目录解析。模块初始化只执行一次，循环导入和根目录外路径会报中文模块错误。

## 错误处理

```text
尝试
    抛出 错误("输入无效")
捕获 原因
    打印(原因.消息)
结束
```

## 图书馆示例

从项目根目录或任意工作目录运行 `examples/图书馆/主.hua`。数据保存在示例目录的 `数据/` 中，菜单包含添加、查询、登记、借阅、归还、查看记录和删除图书。
