# 华言标准库规范 v0.3

标准库通过受控的 Go 原生函数接口提供。原生函数必须检查参数数量和类型，不能访问 VM 私有栈；Go panic 必须转换为华言内部错误。

## 模块

| 模块 | 核心 API |
|---|---|
| 标准.控制台 | 输出、错误输出、读取一行 |
| 标准.文字 | 长度、查找、替换、分割、裁剪、大写、小写 |
| 标准.列表 | 排序、查找、映射、过滤 |
| 标准.字典 | 键、值、条目、包含键 |
| 标准.文件 | 读取文字、写入文字、追加文字、存在、创建目录、原子写入 |
| 标准.JSON | 解析、序列化、格式化 |
| 标准.时间 | 现在、当前时间、解析、格式化、日期差（返回结束时间减开始时间的秒数）、加秒 |
| 标准.数学 | 绝对值、最小值、最大值、取整 |
| 标准.程序 | 参数、环境、受控退出 |
| 标准.测试 | 断言相等、断言错误、注册、运行 |

文件写回必须使用临时文件、刷新和原子替换。JSON 默认将对象解析为保持顺序的记录，数组为列表，整数范围内数字为整数，其余数字为小数。序列化必须检测循环引用。
