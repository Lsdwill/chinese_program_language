# 华言第二阶段增量规范

> 状态：开发中的 v0.4 草案  
> 基线：v0.3 语法和语义规范

## 最后语句

异常语句可以只有捕获、只有最后，或者同时包含两者：

~~~text
尝试
    执行操作()
捕获 原因
    处理错误(原因)
最后
    释放资源()
结束
~~~

规则：

- 尝试语句必须至少包含捕获或最后；
- 最后在尝试体正常完成后执行；
- 捕获体正常完成后执行最后；
- 捕获体再次抛出错误时，最后先执行，再重新抛出新的错误；
- 最后体抛出的错误覆盖正常返回或原错误，并保留错误链；
- 当前草案禁止在包含最后的尝试体、捕获体和最后体中使用返回、跳出、继续；
- 函数声明可以出现在这些代码块中，但函数内部的控制流按函数调用时的上下文处理；
- 没有捕获时，尝试体抛出的错误会在最后执行后继续向外传播。

限制控制流是第一版实现策略，用于避免在字节码中同时处理返回、循环跳转、错误处理区和资源清理。后续版本可以使用统一的控制流退出记录取消此限制。

## 资源对象

资源对象由原生模块创建，用户代码不能伪造。资源对象：

- 按对象身份比较；
- 不能作为字典键；
- 不能序列化为 JSON；
- 关闭操作幂等；
- 使用已关闭资源产生资源错误；
- VM 关闭时由资源管理器按逆注册顺序兜底关闭。

## 不可变字节串与编码

字节串是运行时的一等值，表示任意二进制数据，不等同于文字：

- `标准.编码.UTF8编码` 将文字编码为 UTF-8 字节串；`UTF8解码` 会验证输入，非法 UTF-8 产生编码错误；
- `Base64编码`、`Base64解码` 使用标准 Base64；
- `十六进制编码`、`十六进制解码` 使用小写十六进制文字；
- 字节串索引需要整数，返回对应的无符号字节整数（0～255）；
- 字节串字段 `长度` 按字节计，内置 `长度` 也按字节计；
- 字节串按内容相等，构造时复制输入，因此外部输入变化不会改变其内容；
- 字节串不可变、不能作为字典键、不能直接序列化为 JSON；
- `标准.文件.读取字节` 和 `写入字节` 使用与文字文件 API 相同的路径规则。
