# 华言模块规范 v0.3

每个源文件对应一个模块。模块声明应与相对于项目根的路径一致，例如 `图书馆/服务/借阅.hua` 对应 `模块 图书馆.服务.借阅`。模块顶层代码在当前进程中只初始化一次。

```text
导入 标准.JSON 为 JSON
从 图书馆.服务.借阅 导入 借书, 还书
```

只有 `公开` 声明可以被其他模块读取。用户模块从项目根解析，标准模块使用 `标准.` 前缀。路径必须规范化，不能逃出项目根。模块缓存按规范化路径索引，循环导入必须在初始化完成前报错并显示导入链。

模块只暴露导出名称，不暴露未公开的顶层变量、函数和常量。导入失败、模块名不一致、私有名称导入和循环导入分别属于模块错误，退出码为 3。
