# 华言语法规范 v0.3

程序由可选模块声明、导入声明、公开声明、变量/常量声明、函数声明和语句组成。代码块以中文关键字开始，以 `结束` 结束，语句之间使用换行或分号分隔。

## 声明和代码块

```text
程序 ::= [模块声明] 声明*
模块声明 ::= 模块 模块路径
变量声明 ::= 让 标识符 = 表达式
常量声明 ::= 常量 标识符 = 表达式
函数声明 ::= 函数 标识符 ( 参数列表? ) 换行 声明* 结束
公开声明 ::= 公开 (变量声明 | 常量声明 | 函数声明)
```

条件、循环、遍历和异常语句分别使用 `如果`、`当`、`遍历`、`尝试` 开始，使用 `结束` 结束。条件支持 `否则` 与 `否则如果`。`跳出`、`继续`只能出现在循环中，`返回`只能出现在函数中。

## 表达式

从低到高的优先级为：

1. 赋值 `=`；
2. 或 `或`；
3. 且 `且`；
4. 相等 `==`、`!=`；
5. 比较 `<`、`<=`、`>`、`>=`；
6. 加减 `+`、`-`；
7. 乘除余 `*`、`/`、`%`；
8. 一元 `非`、`-`；
9. 调用、索引和字段访问。

`且`和`或`短路求值。赋值目标必须是已声明变量、索引或记录字段。

## 集合字面量

```text
列表 ::= [ (表达式 (, 表达式)*)? ]
字典 ::= { (表达式 : 表达式 (, 表达式)*)? }
记录 ::= 记录 { (标识符 : 表达式 (, 标识符 : 表达式)*)? }
```
