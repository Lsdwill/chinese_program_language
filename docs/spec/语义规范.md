# 华言语义规范 v0.3

华言是动态强类型、词法作用域语言。变量必须显式使用 `让` 或 `常量` 声明，声明必须带初始化表达式；同一词法作用域不能重复声明。内层作用域可以遮蔽外层名称，但闭包捕获的是绑定单元而不是创建时的副本。

## 值与相等

值类型为：空值、布尔、整数、小数、文字、列表、字典、记录、函数、模块和错误。列表、字典、记录、函数和模块按对象身份比较；整数与小数可以进行数值比较；布尔不是数字。

文字不可变，长度和索引按 Unicode 码点。列表、字典和记录可变，赋值传递对象引用。记录字段保持插入顺序。

## 数字和运算

整数是有符号 64 位整数，小数是 float64。整数与小数混合运算时整数提升为小数。整数加减乘、取负和相关转换必须检测溢出；除以零产生华言运行时错误。`+` 不进行隐式文字转换，文字只能和文字相加。

条件表达式必须是布尔值。`且`和`或`必须短路，并返回布尔值。

## 函数和闭包

参数按值传递；可变对象的值是对象引用。参数数量严格匹配。无显式返回时返回空。函数可以递归、嵌套和作为值传递。调用深度超过 VM 限制时产生华言调用栈错误。

## 错误

只有错误对象可以被 `抛出`。错误包含类别、消息、源码位置和华言调用栈。`尝试 ... 捕获 名称 ... 结束` 捕获当前错误；捕获代码可以继续执行或再次抛出。未捕获错误以退出码 1 终止程序。
