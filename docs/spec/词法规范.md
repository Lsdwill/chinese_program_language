# 华言词法规范 v0.3

## 编码与位置

源文件必须是 UTF-8。允许一个 UTF-8 BOM，Lexer 必须忽略 BOM，但 SourceSpan 的字节偏移仍以原始文件开头为基准。换行统一按 LF 解释，CRLF 和 CR 输入必须映射到同一行模型。字符列按 Unicode 码点从 1 开始，字节偏移按原始 UTF-8 字节计算。

字符串内容不做 NFC 规范化；标识符比较前执行 NFC 规范化，并保留原始拼写用于诊断。

## 标识符

标识符首字符必须满足 Unicode XID_Start 或为下划线，后续字符必须满足 Unicode XID_Continue 或为下划线。数字不能作为首字符，Emoji 不能作为标识符。关键字经过同样的规范化后匹配。

## 关键字

`模块`、`导入`、`从`、`为`、`公开`、`让`、`常量`、`函数`、`返回`、`如果`、`否则`、`否则如果`、`结束`、`当`、`遍历`、`于`、`跳出`、`继续`、`真`、`假`、`空`、`且`、`或`、`非`、`尝试`、`捕获`、`抛出`、`记录` 是保留字，不能作为普通名称。

`否则如果`既可以写成连续关键字，也可以写成 `否则 如果`。标准库名称不是保留字。

## 注释、换行与标点

支持 `//` 单行注释和 `/* ... */` 非嵌套多行注释。括号、方括号和大括号内部的换行不结束语句；运算符之后的换行不结束表达式；分号可以结束语句。语句结束默认使用换行。

字符串外接受 `（ ）［ ］｛ ｝，：；` 作为 ASCII `()[]{},:;` 的等价写法，字符串内必须保持原样。

## 字面量

支持十进制 64 位整数、IEEE 754 双精度小数、双引号 UTF-8 文字、`真`、`假`、`空`、列表、字典和记录。整数和小数只接受阿拉伯数字；整数溢出属于运行时错误。
