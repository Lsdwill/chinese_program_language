# 华言 v0.3.0

## 主要内容

- UTF-8/BOM、NFC 标识符、中文诊断和 Source Manager；
- Resolver 局部槽位、显式局部/上值字节码、闭包和调用栈限制；
- 字节码验证器、反汇编中的槽位和函数原型信息；
- 模块缓存、循环导入链、项目根边界和标准库；
- REPL 多行输入、`check`、`dis`、`fmt --check` 和 `test`；
- 模块化图书馆示例、业务测试和相对路径启动；
- Linux amd64、Windows amd64、macOS amd64/arm64 发布包、源码归档与 SHA256 校验和。

## 验证状态

- `go test ./...`、`go test -race ./...`、`go vet ./...` 已通过；
- Lexer、Parser、字节码验证器的固定 Fuzz 测试已通过；
- `tests/conformance/` 已覆盖词法、语法、作用域、数字、文字、列表、字典、记录、函数、闭包、错误和标准库基线；
- 当前总体语句覆盖率为 83.1%；所有核心 `internal` 包均达到开发计划要求的 85% 门槛。总体数字包含 CLI 入口包，CLI 黑盒验收另行执行。

## 已知边界

本版本不包含类、泛型、协程、数据库驱动、HTTP 客户端或包管理器。字节码格式不提供跨版本兼容承诺。
