# 标准库 API 速查

标准模块通过 `导入 标准.模块 为 名称` 使用。参数数量或类型错误都会返回华言错误对象。

| 模块 | API |
|---|---|
| 控制台 | `输出(...)`、`错误输出(...)`、`读取一行()` |
| 文字 | `长度(文字)`、`查找(文字,目标)`、`替换(文字,旧,新)`、`分割(文字,分隔符)`、`裁剪(文字)`、`大写(文字)`、`小写(文字)` |
| 编码 | `UTF8编码(文字)`、`UTF8解码(字节串)`、`Base64编码(字节串)`、`Base64解码(文字)`、`十六进制编码(字节串)`、`十六进制解码(文字)` |
| 列表 | `排序(列表)`、`查找(列表,目标)`、`映射(列表,函数)`、`过滤(列表,函数)` |
| 字典 | `键(字典)`、`值(字典)`、`条目(字典)`、`包含键(字典,键)` |
| 文件 | `读取文字`、`写入文字`、`读取字节`、`写入字节`、`追加文字`、`存在`、`创建目录`、`原子写入`、`原子写入组` |
| 数据库 | `打开`、`关闭`、`建表`、`插入`、`选择`、`选择一行`、`更新`、`删除`、`开始事务`、`提交`、`回滚`、`最后插入编号`、`受影响行数` |
| JSON | `解析`、`序列化`、`格式化` |
| 时间 | `现在`、`当前时间`、`解析(文字,布局)`、`格式化(时间,布局)`、`日期差(开始,结束)`、`加秒(时间,秒数)` |
| 数学 | `绝对值`、`最小值`、`最大值`、`取整` |
| 程序 | `参数`、`环境`、`退出([状态码])` |
| 测试 | `断言相等`、`断言错误`、`测试`、`运行` |

时间输入使用 RFC3339；`日期差`返回结束时间减开始时间的整数秒。文件相对路径以当前执行模块目录为基准，`原子写入`会在替换前保存 `.bak` 备份。

字节串是不可变的二进制值：构造时复制输入，索引返回 0 到 255 的整数，`长度`按字节计。字节串不能作为字典键，也不能直接序列化为 JSON。
