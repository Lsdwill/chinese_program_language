# 错误信息与故障排查

华言错误分为编译诊断和运行时错误。编译诊断包含源码文件、行列位置、错误码和修复提示；运行时错误会显示类别、消息和华言调用栈。

## 常见错误类别

| 类别 | 含义 | 常见处理 |
| --- | --- | --- |
| 语法错误 | 代码结构不完整或关键字位置错误 | 检查括号、`结束` 和字符串引号 |
| 名称错误 | 名称未声明、重复声明或尚未初始化 | 先用 `让`、`常量` 或 `函数` 声明 |
| 类型错误 | 运算、索引或调用的值类型不匹配 | 用 `类型(值)` 检查实际类型 |
| 模块错误 | 模块找不到、路径越界或名称不匹配 | 从项目根检查模块声明和文件路径 |
| 文件错误 | 文件不存在、权限不足或数据损坏 | 检查路径、权限和 JSON 内容 |
| 测试错误 | `标准.测试` 断言失败 | 查看断言消息和测试名称 |

## 命令行排查

```bash
huayan check 文件.hua       # 只检查，不执行
huayan dis 文件.hua         # 查看字节码和捕获的上值
huayan fmt 文件.hua         # 输出格式化结果
huayan fmt --check 文件.hua # 检查格式是否已统一
```

如果程序退出码为 2，通常是编译或文件诊断；`标准.程序.退出(n)` 会保留用户指定的状态码 `n`。未处理异常不会输出 Go 调用栈，也不会覆盖持久化文件。

## 数据损坏和备份

图书馆示例读取 JSON 失败时会受控退出，原文件保持不变。原子写入会先生成 `.bak` 备份；恢复前应停止程序，确认备份内容后再替换数据文件。
