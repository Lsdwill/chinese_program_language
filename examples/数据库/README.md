# 中文数据库示例

这个示例演示华言如何连接本地数据库文件，并使用中文数据库 API 完成：

- 创建数据目录；
- 打开 `数据/图书馆.db`；
- 建立图书表；
- 使用事务插入数据；
- 使用 `选择 … 从 …` 查询语法糖；
- 使用 `其中`、`排序` 和 `限制`；
- 更新记录；
- 使用 `最后` 确保数据库关闭。

运行方式：

```bash
huayan examples/数据库/主.hua
```

也可以使用仓库内构建的解释器：

```bash
go build -o huayan ./cmd/huayan
./huayan examples/数据库/主.hua
```

示例会在当前项目目录下创建 `examples/数据库/数据/图书馆.db`。数据库文件属于运行数据，不应提交到源码仓库。
