# 华言图书管理系统

这是一个使用华言和中文数据库模块实现的完整命令行图书管理系统。

## 功能

- 数据库自动初始化；
- 图书新增、查询、删除；
- 读者登记和查询；
- 图书借阅和归还；
- 借阅记录查询；
- 数据库事务插入；
- `最后` 语句保证数据库关闭；
- 数据持久化到 `数据/图书馆.db`。

## 运行

在项目根目录运行：

```bash
huayan examples/图书馆/主.hua
```

或者使用发布包：

```bash
dist/huayan-v0.4.0/huayan-v0.4.0-linux-amd64 examples/图书馆/主.hua
```

系统第一次运行会创建数据库和三张表：`图书`、`读者`、`借阅`。数据库文件位于当前运行目录的 `数据/图书馆.db`。
